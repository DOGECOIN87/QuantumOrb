# T027: local operational endpoints and explicit commands

Readiness checks required database tables and columns, while liveness remains
independent of storage and provider access. Diagnostics and row-count metrics use
an allowlist and never expose configuration URLs, keys, raw bodies or metadata.
Unread database counts are absent rather than fabricated zero values. Local
readiness does not imply live-provider verification; provider/ingestion state
remains explicitly not_read in this API process.

Graph exports are relationship-scoped, bounded to 5,000 edges and twice as many
referenced nodes, with an explicit truncation flag. Mint filtering uses retained
evidence scope. Exports omit raw payloads, node metadata, evidence details and
unrecognized algorithm strings. Expired evidence becomes stale in the read view
without rewriting original observations. Summary endpoints read persisted runs.

The manage CLI provides explicit migration, health, metrics, replay, summary
analysis, export and live intake commands. Export refuses to overwrite a file.
Offline commands force demo transport and make no provider calls. Live intake
and backfill require an explicit --live flag and valid live configuration.
The existing stream supervisor delivers into the same normalization/lifecycle
consumer used by replay. Startup and HTTP reads do not activate ingestion.

Replay verifies retained payload hashes before decoding. Supported fixtures and
compiled raw transactions use existing decoders and pinned normalizers. Unknown
notification contexts, including parsed notifications without archived discovery,
are reported unavailable. Failed fixture transactions cannot become successful
canonical observations on later replay. Raw payloads remain immutable.

No SQL/schema/provider-contract changes. New public read endpoints are additive.
End-to-end tests cover real migrations, offline replay, summary persistence,
HTTP reads, redacted exports, expiry and no-overwrite behavior. Live sessions
remain operationally unverified; automatic finality scheduling is not enabled.
