01 The ledger

Every seal published so far. Each entry carries the hash of the one before it, so none can be dropped, reordered or rewritten without the chain breaking here.

02 One file in one root

An inclusion proof shows that a path and its commitment are a leaf of a published root - and says nothing about any other file.

03 An opened file

Once a file is opened, its salt is published with it. Its bytes and its salt give back the commitment sealed on the day - or they do not.
